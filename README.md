# Sakura CP2 table hash

One-shot, read-only check. This repository does not contain a model and does not publish an Unsloth conversion.

It streams one pinned public byte range from `unsloth/Qwen3.8-Flash-Next-GGUF` revision `766911a6b7369840a91dbcd95f9f997acaab6cd6` and compares its SHA256 with an existing local ISTA table hash. Nothing is written back to Hugging Face.
