# Sakura DeepSeek Flash 1017 family assembly

Authorized scope: finish Maya-XS and seven additional Unsloth variants, retain the three existing releases, then publish the eleven-model overview and English/Chinese comparison cards. Also update only the documentation/provenance of the two newer Flash-Next Unsloth CP2 packages. No model, runtime or starter renames.

`plan.json` freezes every input, output path, size and table header. The four new Unsloth table-header groups share one complete, fully hashed 84.48-GB source read. Each target has its own native Xet streaming session and independent Python/native output hash. Maya-XS reuses the two existing 42.24-GB Q3 payload files with correct XS split headers. No backbone quantization or table requantization is performed. All backbone files are copied server-side with their pinned SHA256 identities. Native metadata caching is small and bounded in configuration; no complete model/table file is materialized on runner disk.

Full streaming/publication refuses local/Work execution. It requires a real public GitHub-hosted standard ubuntu-24.04 runner and the existing explicit HF_TOKEN secret. Only the free personal destination account is accepted. Paid runners/GPUs, inference APIs, full-model inference and quota-neutral deduplication are not used or claimed. Storage/backend rejections stop the job.

The new Maya Q3 source patch is pinned to Project Maya v1.1.22 at ffe2e5e53fd5254e7f3492a20e8ad2b51b26a197, which adds the required IQ1 expert support. It passed isolated scalar CPU parity on 192 real rows, 4096 random blocks and all 63488 finite FP16 scales. In Work's CPU cloud, the actual CUDA kernels, model and IQ1 units compiled, and the GPU fixture executable linked, without GPU execution. This is not a GitHub timing or full executable/inference result; the scope is preserved in evidence/runtime-cuda.json. The exact source patch is reapplied and scalar-tested on the runner before any large input stream.

The release workflow has separate checks, Unsloth, Maya-XS and metadata-only Flash-card jobs. The DeepSeek overview/card job waits for both full assembly jobs to succeed, checks every model's file identities and actual table rows, then publishes the catalog. It never advertises incomplete packages as finished. English cards include source-versus-Sakura byte/GB/GiB comparisons, unchanged/changed components, exact source revisions, runtime instructions, test limits, file SHA256 lists and collapsed Chinese. Personal build links are excluded from all public model metadata.

Local small/offline checks: `python test_streaming.py` exercises all four header streams against a real native local CAS, plus corruption/length rejection. `python test_cards.py` checks provenance, licenses and privacy. `check_runtime_cpu.py` needs the patched source and pinned GGML base library. `compile_runtime.py` only compiles/links with an existing SDK; it never executes a GPU test.
